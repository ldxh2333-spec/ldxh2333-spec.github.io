## 项目与经历

个人脱敏模拟项目。基于教育数字化一线场景，围绕教师问题咨询设计知识库问答、问题分流、人工工单和进度跟进流程，并使用 Coze、Vue、Node.js 完成可交互 Demo、测试集和效果评估。

- [在线作品集](https://ldxh2333-spec.github.io/portfolio/)
- [项目详细说明](https://ldxh2333-spec.github.io/notes/面试准备/项目讲解/教育%20SaaS%20AI%20智能服务台)
- 该项目是个人脱敏模拟 Demo，不连接真实学校系统，不代表生产上线项目。

### AI Job Coach

个人 AI 应用 Demo，面向程序员求职场景，尝试串联岗位 JD 分析、简历辅助、模拟面试和回答复盘等功能，用于练习需求拆解、交互设计和 AI 应用产品化表达。

- [项目梳理](https://ldxh2333-spec.github.io/notes/面试准备/项目讲解/AI%20Job%20Coach%20项目梳理)

### Odoo ERP 模拟实施

2026 年 5 月完成的个人 ERP 模拟实施项目。在 Linux、Docker、Odoo 和 PostgreSQL 环境中练习系统部署、基础配置、日志查看和采购、入库、销售、出库、库存等业务流程。

- [项目说明](https://ldxh2333-spec.github.io/notes/面试准备/项目讲解/Odoo%20开源%20ERP%20模拟实施项目)
- 这是个人模拟实施项目，不是客户现场实施项目。

## 本地运行

```powershell
npm install
npm run docs:dev
```

构建检查：

```powershell
npm run docs:build
```

## 笔记更新

如果需要从有道云导出内容同步公开笔记，可执行：

```powershell
npm run notes:publish
```

该流程会同步公开笔记、本地构建并推送到 GitHub Pages。公开内容会排除账号密码、敏感信息、草稿和明显未完成的内容。
