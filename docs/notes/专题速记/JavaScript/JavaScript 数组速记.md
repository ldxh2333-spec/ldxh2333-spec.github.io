# js中常用的数组速记

## 1️⃣ 基础环境

无需安装，浏览器原生支持。

***

## 2️⃣ 创建示例数组

```javascript
// 准备一个示例数组，后续所有方法都用它演示
const nums = [1, 2, 3, 4, 5];
const users = [
  { id: 1, name: 'Tom', age: 18 },
  { id: 2, name: 'Jerry', age: 20 },
  { id: 3, name: 'Spike', age: 22 }
];
```

***

## 3️⃣ 不改变原数组的方法（⭐推荐）

| 方法            | 作用一句话             | 完整示例（含注释）                                                                           |
| :------------ | :---------------- | :---------------------------------------------------------------------------------- |
| **map**       | 每个元素加工后返回 **新数组** | `const doubled = nums.map(n => n * 2); // [2,4,6,8,10]`                             |
| **filter**    | 过滤出 **符合条件的元素**   | `const adults = users.filter(u => u.age >= 18); // [{id:1...},{id:2...},{id:3...}]` |
| **find**      | 找到 **第一个匹配项**     | `const tom = users.find(u => u.name === 'Tom'); // {id:1,name:'Tom',age:18}`        |
| **findIndex** | 找到 **第一个匹配下标**    | `const idx = users.findIndex(u => u.id === 2); // 1`                                |
| **includes**  | 判断数组是否 **包含某值**   | `nums.includes(3); // true`                                                         |
| **some**      | **只要一个满足**返回 true | `users.some(u => u.age > 20); // true`                                              |
| **every**     | **所有都满足**返回 true  | `nums.every(n => n > 0); // true`                                                   |
| **reduce**    | **累计**成一个值        | `const total = nums.reduce((acc, cur) => acc + cur, 0); // 15`                      |
| **slice**     | **截取片段**（浅拷贝）     | `nums.slice(1, 4); // [2,3,4]`                                                      |
| **concat**    | **合并数组**          | `[1,2].concat([3,4]); // [1,2,3,4]`                                                 |

***

## 4️⃣ 会修改原数组的方法（⚠️慎用）

| 方法          | 作用一句话         | 完整示例（含注释）                                                       |
| :---------- | :------------ | :-------------------------------------------------------------- |
| **push**    | **末尾追加**      | `nums.push(6); // 原数组变为 [1,2,3,4,5,6]`                          |
| **pop**     | **删除并返回**最后一个 | `const last = nums.pop(); // last=5, nums=[1,2,3,4]`            |
| **shift**   | **删除并返回**第一个  | `const first = nums.shift(); // first=1, nums=[2,3,4,5]`        |
| **unshift** | **头部插入**      | `nums.unshift(0); // 原数组变为 [0,1,2,3,4,5]`                       |
| **splice**  | **增删改万能刀**    | `nums.splice(1,2,'a','b'); // 从下标1开始删2个再插入2个 → [1,'a','b',4,5]` |
| **reverse** | **反转顺序**      | `nums.reverse(); // 原数组变为 [5,4,3,2,1]`                          |
| **sort**    | **排序**        | `[3,1,2].sort((a,b) => a-b); // [1,2,3]`                        |

***

## 5️⃣ 速查口诀（一行背完）

| 目的     | 一行代码                             |
| :----- | :------------------------------- |
| 每个元素翻倍 | `arr.map(x => x * 2)`            |
| 过滤成人   | `arr.filter(u => u.age >= 18)`   |
| 求和     | `arr.reduce((a, b) => a + b, 0)` |
| 是否包含某值 | `arr.includes(value)`            |
| 删除最后一个 | `arr.pop()`                      |
| 合并两个数组 | `[...arr1, ...arr2]`（展开运算符）      |

***

> 口诀\
> “map 改、filter 筛、find 找、reduce 算；push/pop 尾头增删，splice 万能剪；不碰原数组用 slice，合并展开最方便。”
