# 开发中经常使用的数组方法-速记笔记

（reduce | Object.keys | map）\
**用途**：数组→新数组、数组→对象、对象→数组，一把梭。

***

## 1. `map` —— 「逐个变形，返回新数组」

**口诀**：一进一出，长度不变。

JavaScript复制

    const nums = [1, 2, 3];
    const doubled = nums.map(n => n * 2);   // [2, 4, 6]

    // 对象数组→只要名字
    const users = [{id:1,name:'Tom'},{id:2,name:'Jerry'}];
    const names = users.map(u => u.name);   // ['Tom','Jerry']

    const apiList = [
      { park_id: 1, park_name: '长青公园' },
      { park_id: 2, park_name: '中山公园' }
    ];

    // 转成前端要的结构
    const tableData = apiList.map(item => ({
      id: item.park_id,
      parkName: item.park_name
    }));
    // 结果：
    // [{ id: 1, parkName: '长青公园' }, { id: 2, parkName: '中山公园' }]

***

## 2. `Object.keys` —— 「把对象所有 key 拉成数组」

**口诀**：钥匙串，顺序稳。

JavaScript复制

    const obj = {b:1, a:2, 3:4};
    Object.keys(obj);   // ["3","b","a"]  （数字键升序+字符串键创建序）

    // 常配合 reduce 拼新对象
    const newObj = Object.keys(obj).reduce((o,k)=>{在·
      o[k] = obj[k]*2;
      return o;
    }, {});   // {3:8, b:2, a:4}

***

## 3. `reduce` —— 「合并成单个值（对象/数组/数字）」

**口诀**：左→右，累加器。

JavaScript复制

    arr.reduce((累加器, 当前元素, 当前索引, 原数组) => {
      // 返回新的累加器
    }, 初始值)

    // 例1：求和
    [1,2,3,4].reduce((sum,n)=>sum+n, 0);   // 10

    // 例2：拼对象（字段映射）
    const baseFields = {
      id:'id',
      parkName: r=>r.parkName||r.parkId,
      uploadTime: r=>r.createTime||''
    };
    const row = Object.keys(baseFields).reduce((o,k)=>{
      const rule = baseFields[k];
      o[k] = typeof rule==='function' ? rule(item) : item[rule];
      return o;
    }, {});
    // 一行代码把后端原始记录 item 变成前端需要的 row
