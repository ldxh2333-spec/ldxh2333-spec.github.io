# 笔记导航

## 推荐阅读顺序

1. 先看 `学习笔记`，了解基础和框架学习路线。
2. 再看 `项目实践`，体现真实开发过程和问题解决能力。
3. 用 `专题速记` 快速查看高频知识点。
4. 最后看 `面试准备`，方便面试场景下快速复习。
