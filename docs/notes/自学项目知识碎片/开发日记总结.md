非常重要的理解：

**`:yyy="xxx"` 永远表示“把 JS 变量 `xxx` 绑定给当前元素/组件的 `yyy` 属性”，\
只是**原生标签**的属性是浏览器认识的，自定义组件的属性是你自己定义的 `props`。**

子组件用 `defineEmits(['yyy'])` 声明一个自定义事件，\
在合适的时机 `emit('yyy', 数据)`，\
父组件用 `@yyy="xxx"` 监听，\
回调函数 `xxx(data)` 就能拿到子组件传过来的数据并做后续逻辑。
