# 1.相对定位，决定定位

### 一、相对定位（`position: relative`）

*   **仍在文档流中**：元素原本占的空间不会被“拿走”。
*   **参考系**：相对于**自己原来的位置**进行偏移。
*   **使用场景**：微调位置、作为绝对定位的“锚点”（即包含块）。

css复制

```css
.box {
  position: relative;
  top: 10px;   /* 向下移动 10px */
  left: 20px;  /* 向右移动 20px */
}
```

***

### 二、绝对定位（`position: absolute`）

*   **脱离文档流**：元素不再占据原来的空间，其他元素会“补上”。
*   **参考系**：相对于**最近的已定位祖先元素**（即设置了 `position: relative / absolute / fixed / sticky` 的元素）进行定位。
*   **使用场景**：精确控制元素位置，如弹窗、悬浮按钮、图标叠加等。

css复制

```css
.parent {
  position: relative; /* 成为子元素的定位参考 */
}
.child {
  position: absolute;
  top: 0;
  right: 0;
}
```

***

### 三、对比总结表

表格复制

| 特性      | 相对定位（relative） | 绝对定位（absolute） |
| :------ | :------------- | :------------- |
| 是否脱离文档流 | ❌ 否            | ✅ 是            |
| 参考系     | 自身原位置          | 最近的已定位祖先元素     |
| 是否保留原空间 | ✅ 是            | ❌ 否            |
| 常见用途    | 微调、做锚点         | 精确定位、层叠布局      |

***

### 四、常见误区提醒

*   ❌ `position: absolute` 不会相对于 `<body>` 定位，除非**所有祖先都没有定位**。
*   ✅ 想让绝对定位元素相对于某个父元素定位，**必须给父元素加 `position: relative`**。
*   ❌ `top: 10px` 不是“向上”移动，而是**向下**移动（top 是“距离顶部”）。

***

# 2.padding和margin

| 属性              | **padding（内边距）**              | **margin（外边距）**        |
| :-------------- | :---------------------------- | :--------------------- |
| **作用区域**        | 元素**内部**，内容与边框之间              | 元素**外部**，边框与其他元素之间     |
| **是否参与背景绘制**    | ✅ 背景色/图会延伸到 padding 区域        | ❌ 背景不会覆盖 margin 区域     |
| **是否会被点击/触发事件** | ✅ 会                           | ❌ 不会（空白透明区域）           |
| **是否参与盒模型总尺寸**  | ✅ `width/height` 包含 padding\* | ❌ 不计入元素本身的宽高           |
| **垂直方向合并（塌陷）**  | ❌ 不会                          | ✅ 相邻块级元素的垂直 margin 会合并 |
| **负值**          | ❌ 不允许                         | ✅ 可以设为负值，用于重叠或拉近距离     |
| **常见用途**        | 撑开内部空间、增大点击区域                 | 控制元素间距、水平居中(`auto`)    |

\* 当 `box-sizing: content-box`（默认）时，`width/height` **不包含** padding；\
若设置 `box-sizing: border-box`，则 `width/height` **包含** padding 与 border，但仍**不包含** margin。

一句话记忆：\
**“padding 是房子里的家具占地，margin 是房子与房子之间的空地。”**

# 3.`cursor: pointer;`

`cursor: pointer;` 的作用一句话：\
**把鼠标指针变成“手型”**（就像超链接那样），提示用户“这里可以点击”。

`calc()` 是 CSS3 引入的一个**计算函数**，允许你在声明属性值时，**把不同单位（%、px、em、vh、rem…）混在同一行里做四则运算**，浏览器在渲染时实时算出结果。

语法：

css复制

    属性: calc(表达式);

关键点

1.  支持 `+ - * /` 四种运算符。
2.  **运算符两边必须有空格**。\
    ✅ `calc(100% - 20px)`\
    ❌ `calc(100%-20px)`
3.  可以在任何接受 `<length>`、`<frequency>`、`<angle>`、`<time>`、`<percentage>` 等数值型属性里使用。
4.  可以嵌套 `min()`、`max()`、`clamp()` 等新的数学函数（现代浏览器）。
5.  计算在浏览器端实时完成，能响应窗口大小、字体变化等动态场景。

常见示例

css复制

    /* 宽度：父容器 100% 减去左右各 10px 内边距 */
    width: calc(100% - 20px);

    /* 高度：视口高度减去固定头部 60px */
    height: calc(100vh - 60px);

    /* 字体大小：根字号 × 1.2 再减 2px */
    font-size: calc(1.2rem - 2px);

    /* 网格：三列，每列占 1fr，但中间有 20px 间隔 */
    grid-template-columns: 1fr calc(1fr - 20px) 1fr;

    /* 现代写法：宽度介于 300px 和 50% 之间 */
    width: clamp(300px, 50%, 800px);
