# 2.做的事情

1.  PS D:\git\park\_admin\_web> npm run dev > lhjg-web\@2.11.0 dev > NODE\_OPTIONS=--openssl-legacy-provider vue-cli-service serve 'NODE\_OPTIONS' 不是内部或外部命令，也不是可运行的程序 或批处理文件。

    编辑

    复制

    分享

    这是 **Windows PowerShell 不识别类 Unix 语法** 导致的——\
    `NODE_OPTIONS=--openssl-legacy-provider` 只能被 **bash / zsh / git-bash** 识别，**PowerShell 会把它当成一个命令**，所以报错。

    ***

    ### ✅ 最快 2 种解决方式（任选其一）

    #### ① 临时在 PowerShell 里用 **set** 语法

    powershell复制

        $env:NODE_OPTIONS="--openssl-legacy-provider"
        npm run dev

    > 只影响当前窗口，关闭即失效，**最安全**。

    #### ② 一劳永逸：写进 npm 脚本（推荐）

    打开 `package.json`，把 `scripts.dev` 改成：

    JSON复制

        "dev": "set NODE_OPTIONS=--openssl-legacy-provider && vue-cli-service serve"

    再执行：

    powershell复制

        npm run dev

    > Windows / Linux / macOS 都通用，**团队其他同事也不会踩坑**。

    ***

    ### ⚠️ 注意

    *   **不要** 直接 `export NODE_OPTIONS=...`，那是 Linux/Mac 语法。
    *   如果用的是 **Git Bash**，原命令就能跑；但公司电脑通常默认 PowerShell，所以改脚本最省事。

    ***

    ### 一句话总结

    > **PowerShell 里先执行**\
    > `$env:NODE_OPTIONS="--openssl-legacy-provider"`\
    > **再 `npm run dev`，页面就能正常跑起来。**

    ### 所以你每天的活就是

    1.  **按原型图撸页面**

        *   PC 后台用 Vue2 + Element-UI → 工单列表、审批流、权限按钮。
        *   小程序原生 → 拍照、定位、提交工单。

        *   原来纸质“绿化巡查表”有 12 个字段，你就对应写 12 个 `<el-form-item>`，再写一个“提交”按钮，点完调用 `createOrder()`。
